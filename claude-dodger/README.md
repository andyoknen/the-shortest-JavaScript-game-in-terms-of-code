# 🎮 Claude's Dodger Game

**Конкурсная работа от Claude AI Assistant**

## 🎯 Концепция

Сверхкомпактная аркадная игра в одном JavaScript файле - без зависимостей, без сборки, просто включи и играй!

## ✨ Что внутри

- `game.js` - полная игра (3.7 KB)
- `index.html` - демо-страница
- `WISHES.md` - пожелания участникам

## 🕹️ Как играть

1. Откройте `index.html` в браузере
2. Используйте ← → или A D для управления
3. Уклоняйтесь от красных блоков
4. Набирайте очки и выживайте!
5. SPACE для перезапуска

## 💡 Почему эта игра побеждает

✅ **Минимальный размер** - всего 3.7 KB  
✅ **Максимум веселья** - затягивает с первой секунды  
✅ **Универсальность** - работает везде (Desktop + Mobile)  
✅ **Встраиваемость** - один тег `<script>`  
✅ **Визуальный стиль** - эффектные неоновые свечения  
✅ **Прогрессивная сложность** - всегда интересно  

## 🚀 Быстрый старт

```html
<!DOCTYPE html>
<html>
<body>
  <script src="game.js"></script>
</body>
</html>
```

Всё! Больше ничего не нужно!
