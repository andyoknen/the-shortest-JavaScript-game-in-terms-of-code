# 🎮 Dodger Game - The Shortest JavaScript Game

Ultra-compact embeddable JavaScript arcade game for competition.

## Features

- **Single file**: Complete game in one JS file (~3KB)
- **Embeddable**: Easy to integrate anywhere
- **Touch controls**: Works on mobile devices
- **Progressive difficulty**: Gets harder over time
- **Retro neon style**: Beautiful visual effects

## How to Play

- Use **Arrow Keys** or **A/D** to move left and right
- **Dodge** the falling red obstacles
- **Survive** as long as possible to increase your score
- Press **SPACE** to restart after game over

## Quick Start

Simply include the script:

```html
<!DOCTYPE html>
<html>
<body>
  <script src="game.js"></script>
</body>
</html>
```

Or open `index.html` to play immediately!

## File Structure

- `game.js` - Complete standalone game (embeddable)
- `index.html` - Demo page
